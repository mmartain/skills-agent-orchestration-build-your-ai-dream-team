## Project Pulse

This exercise uses a team of GitHub Copilot custom agents to plan and build
Mona's **Project Pulse** dashboard. The team includes:

- **Orchestrator**: coordinates the work and validates the integrated result
- **Planner**: creates the implementation plan
- **Designer**: shapes the UI, accessibility, and visual design
- **Coder**: implements the dashboard and launch configuration

The agent definitions live in [`.github/agents/`](.github/agents/), and the
team workflow is summarized in [`docs/agent-team.md`](docs/agent-team.md).

Remember, it's self-paced so feel free to take a break! ☕️
